# Map review

Checks for choropleths, symbol maps, and other value-bearing maps.

**Time:** 20 to 40 minutes

**Audience:** Cartographer, analyst, or reviewing agent.

## 1. Provide a text route

A table or ranked list carries the same values. The map is not the only way in.

Rules: [M1](../docs/rules/maps.md#m1), [M8](../docs/rules/maps.md#m8).

## 2. State the geography

Name the projection, extent, scale, boundary vintage, and source.

Rules: [M2](../docs/rules/maps.md#m2), [M4](../docs/rules/maps.md#m4).

## 3. Explain the encoding

The legend names the colour or size encoding, its units, and its class breaks.

Rules: [M3](../docs/rules/maps.md#m3), [C7](../docs/rules/colour.md#c7).

## 4. Do not rely on colour

Patterns, boundaries, labels, or values carry the class as well as colour.

Rules: [M5](../docs/rules/maps.md#m5), [C5](../docs/rules/colour.md#c5).

## 5. Separate missing from zero

Missing or unreliable areas look different from a true zero and are named in the legend.

Rules: [M6](../docs/rules/maps.md#m6), [S8](../docs/rules/states.md#s8).

## 6. Check keyboard navigation

Zoom, pan, and reset work from the keyboard with no trap.

Rules: [M7](../docs/rules/maps.md#m7), [A4](../docs/rules/accessibility.md#a4).
