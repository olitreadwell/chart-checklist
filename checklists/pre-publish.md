# Before you publish

A short pass for a chart that is about to go on a public page.

**Time:** 15 to 30 minutes

**Audience:** Author, editor, or reviewing agent.

## 1. Check the claim

Read the page heading, the chart title, and the subtitle together. They must name the same measure, place, and period.

Rules: [D1](../docs/rules/data-honesty.md#d1), [N1](../docs/rules/narrative.md#n1), [N5](../docs/rules/narrative.md#n5).

## 2. Check the source and the date

Find the publisher, dataset, and as-of date without leaving the chart section.

Rules: [D3](../docs/rules/data-honesty.md#d3), [S6](../docs/rules/states.md#s6).

## 3. Check the encoding

Name the relationship. Confirm the chart type and the zero baseline match it.

Rules: [E1](../docs/rules/encoding.md#e1), [D4](../docs/rules/data-honesty.md#d4), [D6](../docs/rules/data-honesty.md#d6).

## 4. Check the reader path

Read the chart with the keyboard and the data table. Every value must be reachable without a mouse.

Rules: [A1](../docs/rules/accessibility.md#a1), [A3](../docs/rules/accessibility.md#a3), [A4](../docs/rules/accessibility.md#a4).

## 5. Check the screen sizes

Open the page at 320px, 768px, and 1280px. Look for clipped labels and horizontal scroll.

Rules: [R1](../docs/rules/layout.md#r1), [R2](../docs/rules/layout.md#r2).

## 6. Check the failure states

Force an empty dataset, a single point, a flat series, and a fetch error. Each state must explain itself.

Rules: [S1](../docs/rules/states.md#s1), [S2](../docs/rules/states.md#s2), [S3](../docs/rules/states.md#s3), [S4](../docs/rules/states.md#s4).
